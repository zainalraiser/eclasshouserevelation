# E-Clas House Revelation — V9 Audio Ceremony

V9 baseline: V8 + ceremonial audio system.

## Audio flow
- Star Altar: `assets/audio/star-altar.ogg` — calm celestial ambient loop.
- Awakening: `assets/audio/star-awakening.ogg` — short rising celestial sequence.
- Mentor Revelation: `assets/audio/mentor-reveal.ogg` — two-star reveal atmosphere.
- Aldebaran Revelation: `assets/audio/reveal-aldebaran.ogg` — bright/resolute blue-house reveal.
- Sirius Revelation: `assets/audio/reveal-sirius.ogg` — deeper/powerful red-house reveal.

The tracks bundled in this prototype are original procedural audio created for this prototype, so the website works offline without relying on an external audio URL.
